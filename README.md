# 试穿助手（outfitexpert）

帮年轻人在下单前决定「买不买、合不合身」：上传全身照 + 衣服图，生成试穿效果图和合身判断（不输出具体尺码，只给「合身 / 偏紧 / 偏松 + 放量 + 建议方向」）。

- 需求文档：`memory-bank/prd.md`
- 实施计划：`memory-bank/plan.md`
- 开发规范：`CLAUDE.md`

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 <http://localhost:3000>（手机优先布局，建议用浏览器手机模拟视图查看）。

## 当前阶段

**M1 ~ M2 已完成**：上传（人像不强制全身；衣服图带 ❓ 配饰提醒）→ 校验（身高体重必填）→ 腾讯云 MPS 真实换装出图（约 20~60 秒）→ 合身判断（浏览器本地计算，不输出具体尺码）。含失败重试、每人每天 10 次上限。

运行前需在 `.env.local` 填好腾讯云密钥和 COS 桶（文件内有注释说明）。
