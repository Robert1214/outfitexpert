# 试穿助手（outfitexpert）

帮年轻人在下单前决定「买不买、合不合身」：上传人像照 + 1~4 张单品图，生成试穿效果图和合身判断（不输出具体尺码，只给「合身 / 偏紧 / 偏松 + 放量 + 建议方向」）。桌面端为双栏布局，每个单品格可选衣服/配饰/鞋，结果图支持悬停对比原图。

- 需求文档：`memory-bank/prd.md`
- 实施计划：`memory-bank/plan.md`
- 开发规范：`CLAUDE.md`

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 <http://localhost:3000>（手机 / 桌面自适应）。

## 当前阶段

**M1 ~ M2.1 已完成，M2.2 进行中**：上传（人像不强制全身；单品图最多 4 张，每格可选衣服/配饰/鞋，带灰色 ? 配饰提醒）→ 校验（尺寸全部选填）→ 腾讯云 MPS 真实换装出图（约 20~60 秒）→ 合身判断（浏览器本地计算，不输出具体尺码）。4 图（3 衣服 + 眼镜配饰）复测通过；桌面双栏 + 结果页悬停看原图 + 再来一次原地重生成 + 刷新不重复扣费；含失败重试、每人每天 10 次上限。

运行前需在 `.env.local` 填好腾讯云密钥和 COS 桶（文件内有注释说明）。
